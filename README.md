# Анализ лояльности пользователей Яндекс Афиши

## Описание проекта

Проект посвящён анализу поведения и лояльности пользователей сервиса Яндекс Афиша. На основе данных о заказах билетов построены профили пользователей, выявлены факторы, влияющие на возвратность, и сформулированы рекомендации для отдела маркетинга.

## Структура репозитория

- \Project_Yandex_afisha.py\ — основной файл с анализом (Jupyter Notebook в формате .py)
- \equirements.txt\ — зависимости проекта
- \.gitignore\ — файлы, исключённые из репозитория
- \.env\ — параметры подключения к базе данных (не попадает в репозиторий)

## Установка и запуск

1. Клонируйте репозиторий:
   \\\ash
   git clone https://github.com/AlexandrNkE/Yandex-Afisha-analysis.git
   \\\

2. Создайте виртуальное окружение:
   \\\ash
   python -m venv venv
   \\\

3. Активируйте окружение:
   \\\ash
   # Windows
   venv\Scripts\activate
   \\\

4. Установите зависимости:
   \\\ash
   pip install -r requirements.txt
   \\\

5. Создайте файл \.env\ с параметрами подключения к базе данных (см. шаблон в проекте).

6. Запустите Jupyter Notebook:
   \\\ash
   jupyter notebook
   \\\
